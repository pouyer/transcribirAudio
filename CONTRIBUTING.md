# Guía de Contribución

¡Gracias por tu interés en contribuir a este proyecto! Aquí están las directrices para contribuir.

## 🐛 Reportar Bugs

Antes de crear un reporte de bug:
- Verifica que el bug no haya sido reportado ya en [Issues](../../issues)
- Verifica que tienes FFmpeg instalado correctamente
- Asegúrate de que tu entorno virtual está activado

**Para reportar un bug, incluye:**
- Versión de Python (`python --version`)
- Sistema operativo
- Versión de ffmpeg (`ffmpeg -version`)
- Comando exacto que ejecutaste
- Mensaje de error completo

## 💡 Sugerir Mejoras

Las sugerencias son bienvenidas. Abre un issue describiendo:
- El problema actual
- La solución propuesta
- Ejemplos de cómo funcionaría

## 🚀 Pull Requests

### Proceso
1. Fork el repositorio
2. Crea una rama para tu feature (`git checkout -b feature/AmazingFeature`)
3. Commit tus cambios (`git commit -m 'Add some AmazingFeature'`)
4. Push a la rama (`git push origin feature/AmazingFeature`)
5. Abre un Pull Request

### Estándares
- Sigue PEP 8 para el código Python
- Agrega docstrings a funciones nuevas
- Prueba tu código antes de hacer push
- Actualiza la documentación si es necesario

## 📝 Licencia

Al contribuir, aceptas que tus contribuciones estén bajo la Licencia MIT.

¡Gracias! 🎉
